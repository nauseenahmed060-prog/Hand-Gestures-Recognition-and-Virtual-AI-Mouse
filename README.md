# Hand-Gestures-Recognition-and-Virtual-AI-Mouse

My project is a Hand Gesture Recognition and Virtual AI Mouse developed using Python and computer vision. It uses a webcam to detect hand gestures and track finger movements in real time. Based on the detected gestures, it controls the mouse cursor and performs actions such as clicking without requiring a physical mouse. I used OpenCV for image processing, MediaPipe for hand tracking, and PyAutoGUI for mouse control.
